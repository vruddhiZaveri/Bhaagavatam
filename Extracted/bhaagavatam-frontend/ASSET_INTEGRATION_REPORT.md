# Bhaagavatam — Uploaded asset integration

All 46 supplied PNG images have been converted into optimized WebP files under `public/art/`, retaining numbered, descriptive names. Existing image aliases were replaced so the current frontend uses supplied artwork. The gold wordmark and B monogram have been added under `public/branding/`.

The Home hero uses the supplied Krishna–Arjuna panoramic illustration; story posters, featured banners, audio cover, Journey artwork, episode thumbnails, and Universe character portraits use supplied images.

**Limitations:** This ZIP contains images only. The Watch and Listen experiences remain preview/demo interfaces; actual playable MP4, MP3, and subtitle files were not provided. Some uploaded artworks contain baked-in text or black backgrounds. Transparent extraction and further crop adjustments would require a separate visual QA pass.

Full mapping: `ASSET_MANIFEST.json`.
